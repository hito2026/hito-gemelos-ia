# Wiki pública de HitoFusion

Este repositorio contiene la wiki pública de HitoFusion. La portada se publica con GitHub Pages desde la rama `main`.

## Estado

`draft` — estructura editorial inicial, pendiente de incorporar y validar las primeras páginas temáticas.

## Estructura

- `index.html`: portada pública e índice editorial.
- `assets/style.css`: estilos del sitio.
- `docs/EDITORIAL.md`: reglas editoriales, vigencia y seguridad de publicación.

## Publicación

GitHub Pages sirve el contenido estático desde la raíz de `main`. Antes de dar por publicada una actualización se debe comprobar la URL resultante y revisar que no contenga información sensible.

## Sensibilidad

Este repositorio es público. No deben incorporarse secretos, credenciales, datos personales o de clientes, conversaciones privadas, contratos, información financiera no autorizada ni detalles internos sensibles.
