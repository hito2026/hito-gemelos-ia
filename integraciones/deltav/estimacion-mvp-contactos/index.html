#Descripción del Servicio

Desarrollo de una capa de integración entre un sistema externo (Emerson DeltaV) y Odoo 17, compuesta por tres componentes:

  1. Middleware REST (FastAPI) con 4 grupos de endpoints: Contactos, Productos, Listas de Materiales y Pagos, más sincronización batch.
  2. Módulo Odoo deltav_connector con modelos, vistas, controladores HTTP y seguridad.
  3. Módulo Odoo integrador_odoo2delta — extiende Ventas (sale.order) y Compras (purchase.order) para notificar automáticamente al sistema externo vía API cuando se crean o confirman documentos.

El diseño técnico ya está documentado (contratos de API, mapeo de campos, estrategia de idempotencia). La implementación se acelera con generación de código por IA, donde el equipo humano supervisa, valida y ajusta.

#Entregables

  1. Middleware REST (FastAPI) con 4 grupos de endpoints + bulk sync
  2. Rate limiting, circuit breaker, logging estructurado
  3. Métricas Prometheus + documentación OpenAPI
  4. Módulo Odoo deltav_connector instalado y funcional
  5. Módulo Odoo integrador_odoo2delta — notificaciones de ventas y compras al sistema externo
  6. Documentación completa (README, API docs, flujo de notificaciones, manual de operaciones)
  7. Despliegue en staging listo para validación

#Supuestos

  • Odoo 17 operativo y accesible desde el inicio
  • DeltaV expone API REST documentada para recibir notificaciones de ventas y compras
  • IA genera ~80% del código correcto (si no, +10-20h)
  • Los contratos de endpoints no sufren modificaciones durante el desarrollo
  • Una sola persona ejecuta con asistencia de IA
  • La infraestructura de staging ya existe
