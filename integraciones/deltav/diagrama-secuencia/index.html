#Propiedades del Middleware

PropiedadDescripción
IdempotenciaPOST con mismo external_ref = upsert (crea o actualiza)
Resolución de IDsCada request consulta Mapping DB: ext_ref → odoo_id
Merge parcialSolo los campos enviados se modifican en Odoo
Idempotency-KeyHeader opcional para prevenir duplicados en reintentos
Rate Limit100 req/min por API Key — 429 Too Many Requests
TimeoutREST: 30s — JSON-RPC: 60s — 504 Gateway Timeout
