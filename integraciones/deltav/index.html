#Integración Deltav — Odoo 17

Versión: 2.0 — Julio 2026
Caso: Deltav
Sección: Integraciones

#Resumen

Integración entre el Sistema Externo Deltav y Odoo 17 compuesta por tres componentes:

  1. Middleware REST → JSON-RPC — Expone endpoints REST/JSON con autenticación JWT, traduce las llamadas al protocolo JSON-RPC nativo de Odoo.
  2. Módulo deltav_connector — Módulo Odoo 17 con modelos, vistas, controladores HTTP y lógica de sincronización DeltaV ↔ Odoo.
  3. Módulo integrador_odoo2delta — Extiende los módulos de Ventas (sale.order) y Compras (purchase.order) de Odoo 17 para notificar automáticamente al sistema externo (DeltaV) vía API cuando se crean o confirman documentos.

#Arquitectura

ComponenteRol
🖥️ Sistema Externo (Deltav)Cliente REST que envía contactos, productos, BoMs y pagos; recibe notificaciones de ventas y compras desde Odoo
⚙️ MiddlewareTraduce REST a JSON-RPC, mantiene la tabla de mapeo external_ref → odoo_id
🧩 deltav_connectorMódulo Odoo 17 — modelos custom, vistas, controladores HTTP y sincronización DeltaV ↔ Odoo
📤 integrador_odoo2deltaMódulo Odoo 17 — hooks en sale.order y purchase.order que notifican al sistema externo vía HTTP POST
🗄️ Odoo 17ERP que recibe y persiste los datos vía JSON-RPC
💾 Mapping DBBase de datos interna del middleware que resuelve IDs externos a IDs de Odoo

#Entidades soportadas

  1. Contactos (res.partner) — Clientes y proveedores con contactos hijos
  2. Productos (product.template + product.product) — Con variantes, atributos, impuestos y proveedores
  3. Lista de Materiales (mrp.bom + mrp.bom.line) — BoMs con componentes
  4. Pagos (account.payment + account.move) — Cobros y pagos con conciliación de facturas

#Flujo de notificaciones

Odoo 17 ──→ sale.order confirmado ──→ integrador_odoo2delta ──→ HTTP POST ──→ API DeltaV
Odoo 17 ──→ purchase.order confirmado ──→ integrador_odoo2delta ──→ HTTP POST ──→ API DeltaV

#Orden de carga

  1. Contactos
  2. Productos
  3. Listas de Materiales (BoMs)
  4. Pagos
