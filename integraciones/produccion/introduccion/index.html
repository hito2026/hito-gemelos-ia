#Introducción — Integración Odoo Producción

Objetivo, alcance y casos de uso de la API de Integración Odoo Producción v14.

#Objetivo

Conectar un sistema externo de planificación o MES con Odoo para gestionar la demanda de fabricación de extremo a extremo: desde la recepción de una necesidad comercial hasta la ejecución de órdenes de producción, incluyendo la sincronización de maestros compartidos (productos, BOMs, clientes, almacenes).

#Alcance

IncluidoFuera de alcance
Recepción de demanda comercial (Caso A)Gestión de inventario completo (WMS)
Creación directa de órdenes de fabricación (Caso B)Planificación finita de capacidad
Sincronización de maestros primarios: productos y BOMsContabilidad de costos de producción
Sincronización de maestros secundarios: clientes, almacenes, routingsCalidad e inspección
Consulta de estado de órdenes de producciónMantenimiento de equipos
Idempotencia por Idempotency-Key y external_idMigración de datos históricos
Autenticación Bearer TokenSSO o autenticación federada
Resolución de referencias cruzadas por clave externaIntegración con otros módulos Odoo (Compras, Contabilidad)

#Casos de uso

#Caso A — Demanda por venta

El sistema externo informa una demanda comercial (pedido de cliente). La API registra la venta en Odoo, que dispara el flujo de fabricación mediante su motor de reabastecimiento (MTO/MTS).

Endpoint: POST /api/v1/case-a/sales-orders

Flujo: pedido externo → sale.order → confirmación → reabastecimiento MRP → mrp.production

Cuándo usarlo: cuando existe un cliente, un pedido formal y se necesita trazabilidad venta → producción.

#Caso B — Producción directa

El sistema externo actúa como planificador y decide directamente qué fabricar. La API crea la orden de producción en Odoo con los datos de planificación (producto, BOM, cantidad, fechas, routing).

Endpoint: POST /api/v1/case-b/manufacturing-orders

Flujo: orden externa → mrp.production → confirmación → planificación → work orders

Cuándo usarlo: cuando el sistema externo es el planificador maestro (MES/APS) y Odoo ejecuta la fabricación.

#3. Sincronización de maestros

Antes de operar los casos A o B, los maestros deben estar sincronizados:

MaestroEndpointObligatorio para
ProductosPOST /master-data/products/upsertCasos A y B
Listas de materialesPOST /master-data/boms/upsertCasos A y B
ClientesPOST /master-data/customers/upsertCaso A
AlmacenesPOST /master-data/warehouses/upsertCasos A y B

#4. Consulta de estado

El sistema externo consulta el estado consolidado de una orden de producción: avance, cantidades producidas, reservas de componentes y work orders pendientes.

Endpoint: GET /api/v1/status/production-orders/{external_id}
